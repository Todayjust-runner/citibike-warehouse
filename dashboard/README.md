# D：展示与演示

C查询入口已经可用，按[运行说明](../etl/README.md)在本机装载后，完成三类分析：

- 时段：总览、月/日/小时趋势、星期×小时热力图。
- 站点：借还量、净流出排名/趋势，有坐标时展示参考点。
- 类型：会员骑行类型与车型的次数、平均时长、会员占比。

支持日期/车型筛选和时间层级切换。数据来自C的已发布运行，按[C→D契约](../docs/contracts/c-to-d-query-contract.md)处理未知、NULL和覆盖状态；对账后录制关键操作。

[sample-results](sample-results)为C提交的静态格式样例；页面应使用本机当前已发布运行的真实查询。
