# 当前设计决定

| 决定 | 原因 |
|---|---|
| SQL Server 2019、T-SQL、兼容级别150 | 课程工程指定环境 |
| 官方JC固定五包，默认分析2024Q3 | 6月/10月补跨期，数据随私有工程保存 |
| 一个有效ride_id事实，起终时间/站点角色分开 | 同时支持骑行与站点借还六指标 |
| 时长整数微秒，均值/比例重算 | 保留精度和正确汇总 |
| 原始行、重复/排除去向保留 | 能解释数据从哪里来、为什么保留或排除 |
| 未知站点/类型和无坐标骑行保留 | 总量对账完整，地图与真实排名单列未知 |
| 按run隔离事实和站点观察快照 | 重跑不重复累加，不虚构业务SCD2 |
| B设计/DDL已完成，C做ETL/查询、D做展示 | 下一步工作集中在实际实现 |
| 删除重复交付版本、SHA发布清单和脚本自指纹 | Git已经管理代码历史；保留直接影响数据和模型正确性的检查 |
| 原始ZIP只校验一次，Mac附属文件直接跳过 | 固定来源已明确，无需重复解析元数据二进制头 |

业务口径见[需求说明](../requirements.md)，模型细节见[设计入口](../design/README.md)。历史决定可从Git提交记录查阅。
