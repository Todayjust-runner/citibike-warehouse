1. 读取现有需求、决定、缺口和 A p3、5-7；复核 Kimball 四步法的业务过程、粒度、维度与事实。输出 `docs/design/conceptual-design.md`。
2. 固定一个骑行事实及两套时间/站点角色，写 `logical-design.md` 和总线矩阵；编辑图源放 `diagrams/`。

6. 更新决定、`docs/planning/STATUS.md` 和根目录导航，交接 B2；检查 Git 内容后提交并同步既有私有仓库。
