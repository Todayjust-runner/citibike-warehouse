## B1 交付检查

- 概念、逻辑和物理三份设计分别存在且能对应课程报告第 3/4/5 章，不能只给 DDL 代替三级设计。
- 维度唯一关联，事实不被连接放大；ID 字符串比较规则、时长微秒 bigint、起终时间精度、星期规则与未知成员可检查。
- M05 不被出发窗口截断；M06 同粒度两侧聚合；M03 已知类型分母与覆盖率；无覆盖/零/NULL 可区分。
- 原始层和事实层粒度不同；源行定位和重复组血缘清晰；互斥排除有可计算守恒式。
- DDL 在目标 SQL Server 2019/150 成功执行，结构、约束、重跑及隔离夹具验证有实际输出。
- C 能依据契约独立实现导入/ETL/查询，D 能明确消费结果及元信息；未约定的事项仍显式开放。
