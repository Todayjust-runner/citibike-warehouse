## 人工语义复核与修正

- 确认只一个完成骑行业务过程；DWS 两侧汇总不是新增明细事实。起终角色、单 run 查询和站点观察快照一致。
- 归还不继承出发窗口；默认 Q3 出发需要边界输入。按结束月的充分条件是有前提的设计推导，未声称已验证五包实际覆盖。
- 未知站点和未知标签保留；M03 只以已识别 member/casual 为分母，另报识别覆盖率；缺坐标不丢骑行。
- 严格原文本重复标准、冲突优先与稳定代表具有可实现规则；与 A 缺失脚本是否相同仍开放，不把 B 技术选择代签为 A 已批准。
- 将源行守恒明确为 VALIDATED/PUBLISHED 门槛，修正“失败/运行中也要求已全量对账”的潜在歧义。
- 精确字符串身份不依赖默认 SQL 等值，源时间不直接套 datetime2(3) 舍入；具体类型/长度和数据库行为由 B2 验证。
- C→D 明确一行总览/集合的形状、错误元信息、数值排序、部分小时回事实、半边覆盖不生成权威净流出；避免 D 把缺覆盖误当正常空集合。
