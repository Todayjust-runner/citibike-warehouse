# 课程要求

依据原位《期末大作业要求.pdf》p1—2、报告模板和答辩提纲，原件保留原位。

## 必须交付

- 每组最多4人，分工明确；题目为“***数仓系统的设计与实现”。
- 使用真实数据，完成需求分析、概念/逻辑/物理设计、实现和可视化。
- 答辩使用PPT，并提前录制关键功能操作。
- 最终提交报告、代码、PPT、视频；包名按组员姓名连接，日期按后续课程通知。

## 报告章节与分工

| 章节 | 内容 | 主要负责人 |
|---|---|---|
| 1—2 | 背景、需求 | A |
| 3—5 | 概念、逻辑、物理设计 | B，正文已提供 |
| 6 | 工具/部署、来源、ETL、分层、KPI实现 | B/C，指标定义由A协助 |
| 7 | 多维分析与可视化 | D |
| 8及分工表 | 结语、总结与成员分工 | 全员 |

评分：完整准确70%、工作量/难度15%、答辩10%、提交完整性5%。课程未指定数据库、页面框架、图表数量或具体截止日；SQL Server 2019为本项目选择。A的24/48小时安排是组内建议，不是教师硬要求。
