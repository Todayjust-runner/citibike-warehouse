报告模板章节为背景、需求、概念、逻辑、物理、系统实现（6.1 工具部署、6.2 数据来源、6.3 ETL、6.4 分层、6.5 KPI）、多维分析与可视化、结语和分工表。答辩提纲覆盖前七部分。B 后续分别提供第 3/4/5 章和 6.1 的实际内容及证据，C 提供 6.3/6.4，A/C/D 对齐 KPI 定义和实现。

评分为内容完整准确 70%、工作量及难度 15%、答辩表现 10%、提交完整性 5%。要求未规定某款数据库、网页框架、图表数量、中期完成比例或具体提交日。SQL Server 2019 是本次用户指定；A 的 24/48 小时安排是组内建议，不是课程通知。

现有参考指南用于组织 Kimball 建模、分层和质量检查；两本书只核实存在与哈希，未宣称全文审阅。课程 ch2 的 PDF p9、p15-16用于三级设计和信息包表达定位。学长报告及 PPT 抽读首页/目录，其电动汽车/Presto 方案不作为本项目技术约束或验收依据。
