# B设计覆盖复核

模型与需求的对应关系如下。字段/键/类型详见[设计入口](../design/README.md)。

| 项目 | 模型支持 |
|---|---|
| M01/M02 | 唯一骑行事实、出发时间、次数1、精确微秒 |
| M03 | 会员类型维度保留member/casual/未知，按已知分母重算 |
| M04/M05/M06 | 起终站和两套事件时间，独立聚合借还后合并 |
| 跨期 | 事实加载五包全部有效输入，窗口查询不预裁 |
| 未知和坐标 | 未知成员0保留总量，坐标质量单列 |
| 来源和重跑 | 原始行/去向/代表可追溯，事实按run隔离 |
| 物理实现 | SQL2019/150，14表/132字段，约束/索引与实库一致 |
