# 六指标与模型支持检查 v1.0


本文将六指标对应到模型字段，定义依据A v1.0 p5—8。固定源已独立核算，数仓查询由C实现；所有运算使用同一个已发布run_id。

记 `F` 为该运行全部有效唯一骑行；`B` 为车型筛选（NULL 表示所有标签含缺失/未识别）；`S={f∈F | L<=started_at<U 且 B}`，`E={f∈F | L<=ended_at<U 且 B}`。开始与结束集合各自生成，不能用 S 再筛结束得到 E。

| 指标 | 事实 / 维度定位 | 计算、分子分母和可加性 | 覆盖前提 |
|---|---|---|---|
| M01 分析骑行次数 | fact.started_at、bike_type_key、trip_count；出发 date/hour | `N=ΣS trip_count`，等于有效唯一行数；互斥集合可加 | departure complete |
| M02 平均骑行时长 | 同 S，duration_us / trip_count | `ΣS duration_us / 60000000 / N`；N=0 返回 NULL；总时长/次数可加，均值不可直接相加/平均 | departure complete |
| M03 会员骑行占比 | 同 S，member_type→精确 member/casual code | `member_count/(member_count+casual_count)`；零已知分母 NULL；另报 `known_count/N`；比率重新计算 | departure complete |
| M04 站点借出次数 | S 的 start_station_key + 出发 date/hour | 各起点/事件桶计数；含未知站点合计=N；站点筛选只作用起点 | departure complete |
| M05 站点归还次数 | E 的 end_station_key + 归还 date/hour | 各终点/事件桶计数；包含窗口前出发；站点筛选只作用终点；不要求合计=N | arrival complete |
| M06 站点净流出次数 | M04/M05 分别按同站/同桶/同车型聚合 | 以两侧键并集全外连接，覆盖充分时缺某侧补 0，`departures-arrivals`；可正可负 | 两角色均 complete |

使用整数次数和微秒，不先将每条/每月时长舍入为分钟。SQL2019 实现时计数用 COUNT_BIG 或充分宽的整数求和，总微秒用足够宽精确数求和；避免 int 微秒差和浮点误差。统一先算精确分子分母，再 HALF_UP 舍入显示；具体返回类型见 C→D 契约。

## 支撑关系与查询路径

- M01-M03 可从 `dws.trip_hourly` 汇总；会员类型保留在该粒度以重算 member、casual、未知覆盖。默认不接受预先只选 member 的构成卡请求。
- Q1 月/日/小时和星期×小时沿出发日期维度汇总；小时桶仍有日期，热力图才按星期/日内小时折叠。不能把两个不同年份的相同月份名误并为一个月。
- M04-M06 可从 `dws.station_hourly` 汇总；DWS 本身由 fact 两侧独立投影后聚合，不能明细互连。所有真实站点排名排除 key=0，但另返未知侧次数和含未知全量合计。
- 请求起止未对齐完整小时，或者需要 DWS 没保留的筛选时，必须回到事实；不能把部分小时取整后复用 DWS。
- 站点列表来源于当前 run 的 dim.station；选择该站筛选每侧事件角色。总览/类型结果无隐含站点双端过滤。车型筛选在两侧完全相同，包括未知车型是否被选入。
- 不把无覆盖的一侧记 0。某侧在 complete 范围内无事件才可计 0；NULL、无覆盖与有效 0 必须由结果状态区分。

## 查询边界示例

| 设计情境 | 应有行为 | 验证的约束 |
|---|---|---|
| 6/30 23:59:00.123 出发，7/1 00:00:00.123 归还 | 对 Q3 是 M05 +1，M01/M04 +0 | 归还不附加出发窗口 |
| 9/30 23:59:00.123 出发，10/1 00:00:00.123 归还 | 对 Q3 是 M01/M04 +1，M05 +0 | 出发需边界文件；净流出可非零 |
| 同一有效 ride_id 的 3 条完全相同源行 | 1 ACCEPTED、2 DUPLICATE_EXACT、1 fact；次数 1 | 原始去重血缘与守恒 |
| 同 ID 有不同 13 字段内容，含一条完全重复 | 全组 REJECTED，无 fact | 冲突优先于留存重复 |
| 同内容组时间无法解析 | 全组 REJECTED，不生成“代表事实” | 无效重复不混入有效次数 |
| 精确 60 秒、24 小时 | 两端均准入；边界外 1 微秒排除 | 整数精度与包含边界 |
| 合法骑行缺终点 ID、缺坐标 | M01/M02 保留；归还计未知；不进地图 | 坐标缺失不删除事实 |
| 同窗 1 member、1 casual、1 未识别标签 | 占比 1/2；识别覆盖率 2/3；总次数 3 | 分母不直接取所有骑行 |
| complete 窗口无有效骑行 | 次数/时长合计 0，平均/占比/识别覆盖率 NULL | 真实空集合与零分母 |
| 某月包缺失但查询无行 | insufficient_coverage；不返回权威 0 | 缺覆盖不冒充空集合 |
| 两天的均值不同且次数不同 | 用合计微秒/合计次数重算 | 不平均均值 |
| 仅结束时间落在 10 月的 9 月出发骑行 | 留在 fact；按查询时间角色参与或不参与 | 事实不预裁 Q3 出发 |

这些示例定义查询应有的行为。固定源已核对10次进入/11次流出、334332次骑行和净流出1；C实现后还需对照源核算验证自己的查询。
